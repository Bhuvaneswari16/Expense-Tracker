# Expense Tracker

A web-based Expense Tracker developed using Python, Flask, SQLite, HTML, and Bootstrap.

## Features

- User Registration
- Login Authentication
- Logout
- Add Expense
- View Expenses
- Edit Expense
- Delete Expense
- Search Expenses
- Dashboard

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- Bootstrap

## Database

- expenses.db

## How to Run

1. Open terminal in project folder
2. Run:

py app.py

3. Open browser:

http://127.0.0.1:5000
